## 3. Requirement B: Provenance and Semantic Capability Disagreement

1. **Stock Origin Provenance Without Spoofable Markers & Composition-Boundary Validation:**
   - Spoofable `IsStock*` marker interfaces were eliminated in favor of unexported composition-origin flags passed exclusively from stock host construction sites.
   - `featurehost.Runtime` tracks unexported `conversationStoreStock bool`, set to `true` when created by `featurehost.ProcessServices`.
   - `featurehost.Runtime.CompileGeneration` sets `ConversationReaderStockOrigin: r.conversationStoreStock && r.conversationStore != nil` on `featurehost.CorePorts`.
   - `candidate_compile.go` calls `resolveCandidateConvReader(opts.CorePorts, ps.StandardFeatures)` at the candidate composition boundary. This verifies that any reader asserting `ConversationReaderStockOrigin: true` is genuinely identical to `ps.StandardFeatures.ConversationReader()`. If an overridden, custom, or forged reader is passed with `ConversationReaderStockOrigin: true`, the composition boundary overwrites stock origin to `false` (`TestStockHost_ForgedConversationReaderStockOrigin_OverwrittenAndDeclined`).
   - `build_large_body_assessor.go` sets `census.Ports.ConversationReaderFreshALegSupported = in.In.ConversationReader != nil && in.In.ConversationReaderStockOrigin`.
   - Custom / overridden readers lacking certified stock origin evaluate to `ConversationReaderFreshALegSupported = false`, triggering an authority static blocker that declines wire execution (`TestStockHost_CustomOverriddenConversationReader_Decline`).
   - Reload continuity preserves stock origin across configuration reloads (`TestStockHost_FastPath_ReloadContinuity`).
2. **Real Capability Disagreement Rejection & Fail-Closed Subsumption:**
   - Verified by `TestStockHost_BehavioralDifferential_CapsResolver_DisagreementRejection` in `internal/core/runtime/stock_authorities_differential_test.go`:
     - Tests disagreement between canonical capabilities and wire capabilities.
     - Asserts fail-closed rejection when canonical and wire semantic capabilities disagree.
   - Verified by `TestStockHost_IsBackendCapsSubsumed_AgreementAndDisagreement` in `internal/infra/runtimebundle/stock_host_reachability_test.go`:
      - Validates exact capability subsumption logic.
      - Fixed `isBackendCapsSubsumed` in `internal/infra/runtimebundle/build_executor.go` to fail closed (returning `false`):
        - When `ResolveCaps` is provided but backend model inventory is missing (`inv == nil`), returns an error, or provides an empty snapshot (`snapshot.Models` empty). Arbitrary custom capability resolvers without a model inventory are blocked and fail closed.
        - Probes streaming capability (`CapabilityStreaming`) across all models (evaluating both canonical and native IDs); if any model lacks streaming support, returns `false`.
        - Accurately limits static subsumption to probing streaming capability (`CapabilityStreaming`) rather than claiming full capability equality; backend request and domain contracts remain mandatory at runtime.
      - Confirms full candidate evaluation without premature pruning before wire gating.

## 4. Requirement C: Historical Fallback Proof on Resumed Session

1. **Scenario & Architecture:**
   - On the same stock host instance with fast-path enabled, a client submits:
     - **Turn 1 (Fresh Large Payload):** Fresh turn with clean baseline (> 1024 bytes). Evaluates wire-eligible; `openWireCalls` increments from 0 to 1, `openCanonicalCalls` remains 0. Response returns `X-LIP-Resume-Token`, `X-LIP-Session-ID`, `X-LIP-A-Leg-ID`.
     - **State Mutation:** Authoritative conversation store (obtained via `hostActiveExecutor(t, host)` and `conversationview.AsStore`) is updated with a `NeverBackend` tag and a `Steering` overlay for that `aLegID`.
     - **Turn 2 (Resumed Historical Turn):** Client sends a large payload with the resume token and session ID, containing the tagged message to drop and steering text.
2. **Verified Behaviors in `TestStockHost_HistoricalFallback_PersistedNeverBackendAndSteering`:**
   - **Precommit Decline:** `AssessLargeBody` declines wire execution because the session contains historical non-forwardable projection requirements.
   - **Canonical Projection & Filtering:** The request falls back cleanly to the canonical path where `snapshotAndProject` filters out the `never-backend-tagged-part` and prepends the steering overlay (`historical-steering-overlay-content`).
   - **Call Counters:**
     - `openWireCalls`: 1 (turn 1 wire stream; turn 2 did NOT invoke wire).
     - `openCanonicalCalls`: 1 (turn 1 did not call canonical; turn 2 incremented canonical open by 1).
   - **Held Permit Identity:**
     - The response header `X-Lip-A-Leg-ID` strictly matches the original `aLegID` from session turn 1, preserving permit continuity.
   - **Fail-Closed Snapshot Invariant:**
     - The executor validates that fresh sessions never have unexpected non-empty projections and fails closed if corrupted.
3. **Producer Transition Across Generations (`TestStockHost_HistoricalFallback_ProducerTransition_ReloadAndResume`):**
   - **Gen 1 Active Producer:** Feature enabled with registered `test-local-turn-producer` on `PlaneLocalTurnHandlers` claiming and tagging messages.
   - **Reload Reconfiguration:** Feature toggled off via configuration reload (`host.Reload`), yielding Gen 2 where `PlaneLocalTurnHandlersOccupied = false`.
   - **Resumption Invariant:** Resumed request (> 1024 bytes) under the existing session declines wire precommit under the SAME permit identity (`X-Lip-A-Leg-ID`), executes via canonical `Open` where tagged messages are stripped and steering overlays are applied.
   - **Subsequent Fresh Fast Path:** Subsequent fresh request (> 1024 bytes) under Gen 2 successfully executes over the wire fast-path (`openWireCalls` increments to 1), demonstrating clean producer lifecycle transition without leaking state across generations.
